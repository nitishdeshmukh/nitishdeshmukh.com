## Overview

### Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack) & [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Testing**: [Vitest](https://vitest.dev/)
- **Package Manager**: [Bun](https://bun.sh/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Analytics**: [OpenPanel](https://openpanel.dev)
- **Storage**: [Cloudflare R2](https://www.cloudflare.com/r2/)

### Features

- Clean, modern responsive design across desktop, tablet, and mobile
- Seamless dark and light themes
- Interactive monogram marks and micro-animations
- GitHub contributions calendar and repository stats
- Embedded Cal.com meeting scheduler
- Downloadable resume / CV and vCard integration
- SEO optimized with [JSON-LD schema](https://json-ld.org), sitemap, and robots.txt
- AI-ready with [/llms.txt](https://llmstxt.org) and raw markdown content negotiation
- Installable as a Progressive Web App (PWA)
- Privacy-friendly analytics with [OpenPanel](https://openpanel.dev)

### Content

Centralized document system powered by MDX:

- Unified content layer for blog posts using MDX (`next-mdx-remote`)
- Dynamic Open Graph image generation (`@vercel/og`)
- RSS feed for content distribution (`/rss`)
- Raw `.md` endpoints for AI agents and LLM readability
